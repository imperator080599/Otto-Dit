# Démarrer OTTO sous Windows

1. Installez Node.js LTS depuis https://nodejs.org — tout laisser par défaut.
2. Clic droit sur le dossier `Otto-Dit` → « Ouvrir dans le terminal » (PowerShell).
3. `cd app`
4. `npm install`
5. `npm run demo`
6. Ouvrez dans votre navigateur l'adresse affichée dans le panneau final.
7. Pour tout remettre à zéro et relancer : `npm run demo`
8. En cas de problème : `npm run diagnostic`
9. Puis envoyez à Claude le fichier `diagnostic-otto.txt` (à la racine du dossier `Otto-Dit`).
