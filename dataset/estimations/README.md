# Estimations — fichiers de calcul de la cliente (synthétiques)

`fae-2025.csv` — le fichier que la direction d'Altiverre (fictive) fournit pour justifier
l'écriture `OD-2025-089` (50 000,00 € de produits à recevoir — factures à établir au
31/12/2025) : par contrat, les jours réalisés non facturés et le taux journalier
contractuel. La somme des produits recalculés (jours × taux) fait exactement 50 000,00 €.

Il se charge dans l'application sur l'écran « Estimations comptables » (point 11a,
ADR-106) : rapprochement à la comptabilité, recalcul ligne à ligne, sondage de la base,
demande de justificatifs (relevés d'activité pour les lignes tirées, contrat pour CHAQUE
taux journalier, note de méthode pour la formule).

Toutes les données sont fabriquées (règle 2).
